# 自然素養判讀

會考自然（111–115 年）、學測自然（107–115 年）與分科物理、化學、生物（107–115 年指考與分科測驗）共 1,753 題的科學素養分析。每一題都標上四項：

- **能力**（參考 PISA 科學素養）：知識辨識（K）、解釋現象（E）、探究設計（I）、數據詮釋（D）
- **資料類型**：無資料、實驗・探究描述、統計圖表・數據、示意圖・裝置圖、照片・影像、生活・科普情境、多重資料
- **常見陷阱**：概念迷思、名詞混淆、計算與單位、圖表誤讀、變因控制、過度推論、條件遺漏
- **判讀提示**：一句解題方向

本專案由 [huikao-analysis](https://github.com/bgjd315-cloud/huikao-analysis) 的自然部分複製而來，與國文、英文、數學、社會版是各自獨立的網站。

## 資料

- `tools/reading_cls.py`：逐題判讀，依試卷（science、xuece-sci、xuece-phy、xuece-chem、xuece-bio）與年度分段，每題一筆「能力 資料 陷阱 提示」，以「｜」分隔，順序與試卷相同；多選題的提示以「多選：」開頭
- `tools/reading_data.py`：把判讀與 `data/` 的題目、答案合併，供頁面與練習卷使用
- `tools/dump_stems.py`：把題目整理成純文字（`work/stems-<試卷>.txt`），逐題判讀時參考
- `data/`：各年度題目、答案與分類（`xuece-earth` 是學測自然中的地球科學題，不另外判讀）
- `assets/`：從官方試卷裁切的題目圖片

## 建置與檢查

```bash
python build.py
python tools/verify.py
```

`build.py` 會檢查每份試卷的題數與判讀數是否一致；推送到 main 後由 GitHub Actions 自動發布到 GitHub Pages。

## 新增一年

1. 依 huikao-analysis 的 `docs/年度更新流程.md` 產生該年度的 `data/<試卷>/<年度>.json` 與題目圖片，複製到本專案
2. 執行 `python tools/dump_stems.py`，在 `tools/reading_cls.py` 補上該年度各試卷的逐題判讀
3. 執行 `python build.py` 與 `python tools/verify.py`
